# 📊 Sales Performance Dashboard

## 📌 Project Overview
The Sales Performance Dashboard is a business intelligence project developed to analyze and visualize sales data for better decision-making. The primary goal of this project is to convert raw sales data into meaningful insights through an interactive and user-friendly dashboard.

This project was built using Microsoft Power BI and focuses on identifying sales trends, evaluating product performance, and comparing regional and category-wise sales to support data-driven strategies.

---

## 🎯 Objectives
- To clean and preprocess raw sales data for accurate analysis
- To analyze sales performance over time (monthly, quarterly, yearly)
- To identify top-performing and low-performing products
- To perform region-wise and category-wise sales comparisons
- To create key performance indicators (KPIs) such as revenue, profit, and growth rate
- To build an interactive dashboard for dynamic data exploration

---

## 🗂️ Dataset Description
The dataset used in this project contains sales-related information such as:
- Order Date
- Product Name
- Category
- Region
- Sales/Revenue
- Profit
- Quantity

---

## 🧹 Data Cleaning & Preprocessing
Data cleaning was performed using Power Query in Power BI:
- Removed null and missing values
- Eliminated duplicate records
- Converted data types (date, numeric fields)
- Extracted time-based fields (Year, Month, Quarter)

---

## 📊 Data Analysis
The following analyses were performed:
- **Time-based Analysis:** Monthly, quarterly, and yearly sales trends
- **Product Analysis:** Identification of top-selling and low-performing products
- **Regional Analysis:** Comparison of sales across different regions
- **Category Analysis:** Evaluation of product categories based on performance

---

## 📈 Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Sales Growth Rate

These KPIs help in understanding overall business performance and tracking growth trends.

---

## 📊 Dashboard Features
- Interactive visuals (line charts, bar charts, pie charts)
- KPI cards for quick insights
- Filters (slicers) for Year, Region, and Category
- Drill-down functionality for detailed analysis
